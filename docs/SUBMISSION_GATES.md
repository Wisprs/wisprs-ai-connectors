# Submission gates

Every gate is fail-closed. `Prepared` means the artifact exists; it does not mean the evidence is complete.

| Gate                                     | Owner                    | Required evidence                                                                        | Status                                                                                                                                |
| ---------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Package structure and schemas            | Distribution engineering | local validator, OpenAI validator, `claude plugin validate --strict`                     | Local validator + `claude plugin validate --strict` green (see `evidence/2026-08-29-package-validation.md`); OpenAI validator pending |
| Public repository and release provenance | Release engineering      | clean public history, branch protection, signed tag, checksums, SBOM/provenance artifact | Pending external repository publication                                                                                               |
| Service security release checklist       | Security                 | all mandatory controls green, no open high/critical finding                              | Pending final release review                                                                                                          |
| OAuth host matrix                        | Identity                 | fresh/revoke/refresh/expiry/denial tests on every host                                   | Pending live host runs                                                                                                                |
| Production-safe smoke                    | SRE                      | synthetic read/command smoke with zero secret or content leakage                         | Pending production release candidate                                                                                                  |
| Capacity certification                   | SRE/FinOps               | signed 30-minute target load, soak, retry burst, cost reconciliation                     | Pending; no capacity claim permitted                                                                                                  |
| Reviewer account                         | Support/Security         | least privilege, synthetic data, secure credential delivery, expiry/rotation owner       | Pending creation                                                                                                                      |
| Legal and listing URLs                   | Legal/Marketing          | public privacy, terms, support pages match listing and data flow                         | Prepared; legal sign-off pending                                                                                                      |
| OpenAI package matrix                    | Distribution QA          | ChatGPT and Codex reviewer cases green                                                   | Pending registered connection                                                                                                         |
| Anthropic package matrix                 | Distribution QA          | Claude Code and Claude connector reviewer cases green                                    | Pending live connector tests                                                                                                          |
| Launch rollback                          | Incident commander       | runtime write kill switch, owner roster, comms templates, previous package retained      | Prepared in service; drill pending                                                                                                    |

Submission is authorized only when every row is green and the release owner records a go decision. Marketplace portal access, business verification, domain challenges, credential delivery, submission, publication, and launch announcements are external actions and require the designated human owner.
